# Nightly news brief

This is a sanitized, one-time snapshot of a production-derived job package. It
shows how a real report job combines a manifest, a locked `uv` command, a thin
Python adapter, policy, and a bounded prompt.

The private `runwisp-job-report` workspace dependency is intentionally omitted.
The snapshot therefore documents real packaging without promising standalone
report generation from this repository.

Live RunWisp scheduler configuration, deployment paths, credentials, token and
chat values, and delivery setup are excluded.
